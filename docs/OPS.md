# 运营操作手册

## 每天要做的事

1. 打开 **https://<your-host>/board/#/entry**
2. 选日期（默认今天）、选团队
3. 粘贴当天日报，或手工填
4. 点「保存并更新看板」→ 1 秒后全站刷新

不需要点「重建数据」——保存时会自动重建。凌晨 06:00 也会自动从 Google 拉一次最新表格。

## 录入页三种填法

### 1. 粘贴日报（推荐）

直接复制后台日报，整段粘进去：

```
Group T01  20/11/26
Total : 102,704
PK star : Member A
MVP : Member B

Member A : 5,636
Member B : 81,819
Member C : 3,995
Member D : 8,769
Member E : 2,485
```

- `PK star` / `MVP` 这类行会自动忽略
- 团队名支持中英泰写法：`T01` / `ทีม T01`
- 日期支持 `20/11/26`、`20/11/2026`、`2026-11-20`、`20.11.26`
- 数字支持千分位 `102,704`、小数、全角 `１０２，７０４`、缩写 `102.7K`
- 分隔符支持 `:` `：` `=` 制表符 空格

### 2. 表单逐项填

团队钻石、观看、PCU、ACU、涨粉、礼物人数、日 KPI、DAY OFF、备注，然后逐个成员填个人钻石。
底部实时显示「成员合计」，和团队钻石不一致会亮黄字提醒。

### 3. CSV（Excel 导出也行）

```
团队,日期,成员,钻石
T01,2026-11-20,Member A,5636
T01,2026-11-20,Member B,81819
```

或团队级：

```
团队,日期,钻石,观看,PCU,ACU,涨粉,礼物人数
T11,2026-11-20,300000,98000,410,120,520,140
```

## 报错对照表

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 第 N 行：成员「XXX」不在花名册 | 名字写法不对或新人没进花名册 | 用录入页列出的名字，或先把人加进花名册 |
| 第 N 行：无法识别「…」 | 该行既不是 Total 也不是「名字:数字」 | 删掉这行，或改成 `名字 : 数字` |
| 缺少日期：团队 T01 | 没写日期 | 把日期写团队同一行：`Group RT 20/11/26` |
| 日期必须在本账期 … | 日期不在当月 | 检查是否写错月/年 |
| 团队代码不存在 | 团队名拼错 | 看到下拉框里的名字照抄 |
| dia 不能为负数 | 填了负数 | 改成 0 或正数 |
| 录入的团队总额与成员合计差 +N 钻 | 团队总额比成员合计多 | 正常（有人没列出来），会显示差额来源 |

## 录错了怎么办

「已录入」列表里找到那条，点**删除**。删除后该天恢复成记分表原值。

## 数据什么时候生效

保存 → 自动重建（约 0.8 秒）→ 页面自动刷新。所有页面（总览/团队/成员榜/诊断）同时更新，**其他团队的数字不受影响**。

## 录入日志

录入页最下面有「录入日志」：时间、动作（保存/删除/导入）、日期、团队、金额、成员数、来源 IP。最多保留 500 条。

## 看板上的几个提醒怎么看

| 徽章 | 含义 |
|---|---|
| 已积累 19/20 天 · 95% | 该队有 19 天有数据，截止日 20 号；<95% 说明有空白日 |
| 空白 3 | 记分表有 3 天没填钻石 |
| 本队记分表只到 18 日 | 该队数据比别人旧 |
| 含手工录入 1 天（11-21） | 那天是运营补的，不是 Excel |
| 数据 1/16 | 该成员 16 个应录日里只录了 1 天 |
| 未设目标 | 记分表第二行没写 Goal，诊断页会给建议值 |

## 常见问题

**Q：为什么某个成员是「未录入」？**
A：成员个人流水只能靠录入（运营表已移出）。团队流水不受影响。

**Q：为什么团队净利没扣佣金？**
A：没有成员流水时算不出佣金，卡片上标了「未含佣金」和 `*`。

**Q：VJ 版看不到财务数据？**
A：设计如此。VJ 链接只给成绩，服务端就没下发财务字段。
