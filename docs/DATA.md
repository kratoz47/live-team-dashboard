# 数据口径与计算规则

## 一、数据来源

| 级别 | 文件 | 用途 |
|---|---|---|
| 权威 | 11 × `<TEAM> ScoreListGroup.xlsx` | 团队逐日流水、日 KPI、观看/PCU/ACU/涨粉/礼物人数、Day off 名单 |
| 权威 | `VJ Onboarding Record.xlsx`（VJ Roster） | 成员 KPI、底薪、合同、入职、状态、TikTok、主管 |
| 辅助 | `Employee Database (VJ).xlsx` | 运营岗成本（MC / 运营 / Ronin / Lighting），只用于净利 |
| 辅助 | `data/entries.json` | 运营手工录入，优先级高于记分表 |

已移除：运营 gsheet（成员逐日流水）、TikTok 后台导出。

## 二、团队级字段

| 字段 | 定义 |
|---|---|
| 记分表流水 `score.mtd_dia` | Diamond 列逐日相加（含手工录入天） |
| 数据截止 `as_of_day` | `max(记分表最后一天, 该队录入最大日)`，**按队独立** |
| 有数据天数 `data_days` | 截止日内非空白的营业日 |
| 覆盖率 `coverage_ratio` | `data_days ÷ as_of_day` |
| 日 KPI 达标 | 记分表 KPI 列 YES 数 ÷ 已填天数 |
| 观看转化率 `rate_gift` | `送礼人次 ÷ 进房人次 × 100`（%） |
| 人均观看收益 `view_conv` | `流水（钻）÷ 进房人次` |
| 实收 `net_thb` | `流水 ÷ DIA_PER_USD × FX × (1 − 平台抽成)` |
| 团队净利 `profit` | `实收 − 底薪 − 佣金 − 运营成本` |

## 三、成员级字段

| 字段 | 定义 |
|---|---|
| 月 KPI `kpi` | 花名册 Q 列（钻） |
| 考核天数 `kpi_days` | `入职日 → min(队 as_of, 离职日)` 的天数 |
| KPI(MTD) `kpi_mtd` | `月KPI × kpi_days ÷ 30` |
| 个人流水 `dia` | 该成员所有录入天的钻石合计（无录入则空） |
| KPI 进度 | `个人流水 ÷ KPI(MTD)` |
| 底薪(MTD) | `月薪 × 计薪天数 ÷ 30`，计薪天数按公会日历（记分表最大日） |
| 佣金 | `max(0, 个人流水 − KPI(MTD)) × 档位 × FX ÷ DIA_PER_USD` |
| 佣金推演 | 用 `流水 ÷ 考核天数 × 30` 预估月末，再套同一公式，仅参考 |
| 净贡献 | `实收 − 底薪(MTD) − 佣金` |
| 数据覆盖 `data_ratio` | `已录入天数 ÷ (队有数据天数 − 休息天数)` |
| 休息/缺席/培训 | 记分表 Day off 列按人名解析，支持 `名字(ลาป่วย)` 打类型 |

## 四、佣金档位

按**团队月度总流水**分档（非阶梯，全额适用）：

| 月流水 | 档位 |
|---|---|
| ≥ 5,000,000 钻 | 30% |
| ≥ 3,000,000 钻 | 25% |
| ≥ 2,000,000 钻 | 20% |
| 其他 | 15% |

## 五、窗口规则（重要）

- **团队窗口独立**：A 队录到 21 号不影响 B 队的 20 号，KPI 折算、流水、覆盖率都按各自的截止日
- **成员窗口跟着队**：成员 KPI(MTD) 用「本人的入职/离职 ∩ 本队截止日」
- **底薪按公会日历**：薪水按天走，不因某队晚交数据而少算
- **手工录入不抬高全局**：录 21 号不会把 10 个队的成本一起抬高（曾修过这个 bug）

## 六、已知限制（不是 bug，是数据现状）

1. 记分表有空白日（如 11-14 PK 日部分团队空白、某队把团队名写成 "PK COMPANY"）→ 那天流水偏低
2. Day off 列只有名字没有类型 → 目前全部记为「休息」，要区分病假/事假需在单元格加括号
3. 少数 Day off 名字对不上花名册→ 那些休息日不会记到人头上
4. 部分记分表缺观看/PCU/ACU/涨粉列 → 相关指标显示「—」
5. 部分团队无运营成本分表 → 净利偏高
6. 5 个团队未写 GOAL → 目标进度显示「未设目标」，诊断页给建议值
7. 成员流水只有录入的天才有 → 未录入的成员 KPI 进度/佣金为空
8. 佣金档位取自财务文档，未与实发核对

## 七、财务恒等式（对账脚本会验证）

```
实收      = 流水 × (1 − 平台抽成)
运营成本  = 固定成本(按月折算) + MC 费率 + 运营费率
总成本    = 底薪 + 佣金 + 运营成本
净利      = 实收 − 总成本
公会合计  = Σ 各队
逐日合计  = 月度汇总
KPI 合计  = Σ 在职成员 KPI
```
