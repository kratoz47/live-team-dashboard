# 看板页面结构

从「用户打开哪个页面、看到什么、点什么」的角度描述界面。数据口径见 DATA.md，代码见 DEV.md。

## 一、全局框架

```
┌──────────────────────────────────────────────────────────────┐
│ ● 直播团队看板  NOVEMBER 2026                            │
│   总览 · 录入 · 成员榜 · 诊断 · 口径对账   中文/ไทย · ☾ · 重建数据 │
├──────────────────────────────────────────────────────────────┤
│  页面内容（最大宽 1520px，居中）                              │
└──────────────────────────────────────────────────────────────┘
```

顶栏行为：

| 元素 | 行为 |
|---|---|
| 导航 | 当前页高亮（黑色胶囊）。VJ 模式下「录入 / 诊断 / 口径」不显示 |
| 中文 / ไทย | 切换语言，写 localStorage；URL 参数 ?lang=th |
| ☾ / ☀ | 明暗主题，默认跟随系统；URL 参数 ?theme=dark |
| 重建数据 | 重新读 Excel 全量重算（约 0.8 秒）。VJ 模式隐藏 |
| 构建于 … | 显示 dashboard.json 的生成时间 |

## 二、总览页（#/）

| 顺序 | 区块 | 内容 |
|---|---|---|
| 1 | 页头 | 公会总览 + 期间 + 「各队数据各自积累：18–21 日」+ 汇率/抽成 |
| 2 | 6 个核心数字 | 记分表流水 / 实收 / 净利* / 底薪+运营 / 团队·成员 / 日 KPI 达标 |
| 3 | 团队流水排名 | 横向条形图，金色虚线 = 月度目标进度（仅设有目标的队） |
| 4 | 净利排名* | 11 队按净利降序 + 利润率 + 条（VJ 换成 KPI 达标率排名） |
| 5 | 团队卡片 | 每队一卡：流水、目标进度条、目标、日KPI达标、观看转化率、净利、边际/观看/PCU |
| 6 | 结构对账 | 表：流水 / 目标 / 在职KPI合计 / 覆盖率 / 底薪 / 运营 / 净利*（VJ 隐藏） |
| 7 | 预警与洞察 | 逐条：亏损、空白日、无成本表、Day off 未匹配… |

## 三、团队页（#/team/CODE）

| 顺序 | 区块 | 内容 |
|---|---|---|
| 1 | 页头 | 返回、队名、MC、成员数、数据截止、覆盖率徽章（已积累 19/20 天 · 95%）、净利/边际/ROI |
| 2 | 目标环 + 指标网格 | 左：进度环；右：上排 6 格（流水/目标/缺口/日均/人均产出/观看转化率），下排 6 格（观看总量/PCU/ACU/涨粉/礼物/人均观看收益） |
| 3 | 逐日战绩 | 柱状图（绿=达标、蓝=未达标、灰=休息、橙虚线=日目标、灰点线=日均）+ 可展开逐日明细表 |
| 4 | 财务拆解 | 实收 / 底薪 / 佣金 / 运营成本 / 净利*（瀑布条）+ 口径注（含录入天数、差额提示） |
| 5 | 运营岗成本 | MC / 运营 / VJ 逐行，标注「扣底薪 X · 保留 Y」 |
| 6 | 录入差额来源 | 仅当团队总额 ≠ 成员合计时出现：日期/团队额/成员额/差额/未列出的在职成员 |
| 7 | 成员成绩与 KPI | 表格/卡片切换、仅在职、搜索；列：成员/状态/KPI(月)/KPI(MTD)/数据/休息/出勤/合同/入职 |

## 四、成员榜（#/members）

全公会 103 人（可切「仅在职」83 人），按 KPI 降序。
列：团队 / 成员（英文名+泰文名）/ 状态 / KPI(月) / KPI(MTD) / 数据 / 休息 / 出勤 / 合同。
右上「下载全员 PNG」。

## 五、成员抽屉（点任意成员/任意行）

右侧 780px 滑出，手机全屏。

| 区块 | 内容 |
|---|---|
| 头部 | 头像、昵称、团队·合同·入职、状态/主管/TikTok 徽章 |
| 数字格 | KPI(月)、KPI(MTD·N天)、个人流水、KPI 进度、出勤、休息、数据 N/M、合同、入职 |
| 佣金格 | 当前佣金（MTD）+ 按日均推演月末（无录入时不显示） |
| 休息 / 缺席 / 培训 | 按类型分组列日期：休息/请假/病假/事假/缺席/培训 |
| 底部 | 下载成绩单 PNG（VJ 模式不含薪资）、查看团队 |

## 六、录入页（#/entry）

| 顺序 | 区块 | 内容 |
|---|---|---|
| 1 | 录入（团队+个人） | 日期、团队；8 个团队字段（钻石/观看/PCU/ACU/涨粉/礼物/日KPI/DAY OFF）+ 备注；成员逐行填钻石，底部实时合计 |
| 2 | 批量导入 | 粘贴日报或 CSV，或选文件 |
| 3 | 已录入 | 该期间所有录入条目，可删除 |
| 4 | 录入日志 | 时间（+操作人）/动作/日期/团队/金额/成员数/说明+IP |

## 七、诊断页（#/diagnose）

5 个计数条（目标缺口 / 未设目标 / 钻石空白日 / 底薪异常 / 缺数据），下面 8 个区块：
目标与 KPI 建议、成员数据覆盖、数据覆盖、数据缺失、Day off 未匹配、录入差额来源、手工录入、底薪异常（精确到 VJ Roster!S123 这样的单元格）。

## 八、口径页（#/reconcile）

权威口径 6 条 + 已知缺口 5 条 + 数据源清单表。

## 九、VJ 模式差异（/vj/）

| 位置 | 完整版 | VJ 版 |
|---|---|---|
| 导航 | 5 项 | 只有「总览 / 成员榜」 |
| 核心数字 | 流水/实收/净利/成本/人数/达标 | 流水/人数/达标/观看/KPI合计/录入天数 |
| 排名 | 净利排名 | KPI 达标率排名 |
| 团队页 | 含财务拆解、运营成本 | 全部隐藏，成员表无底薪列 |
| 抽屉 | 含底薪、佣金、推演 | 隐藏薪资，其余保留 |
| 结构对账 / 诊断 / 口径 | 有 | 全部隐藏 |
| 写入 | 允许 | 403 |

## 十、移动端

- 顶栏：品牌名截断、导航横向滚动、语言切换收窄、重建按钮变圆形图标
- 6 个 KPI → 2 列；卡片/表单全部单列
- 表格：可横滑、首列吸附；成员表自动隐藏「状态/合同/入职」
- 图表：可横滑（最小宽度 640px），不压扁
- 抽屉：全屏

## 十一、组件清单

| 组件 | 用途 | 出现位置 |
|---|---|---|
| KPI 卡 | 大数字 + 单位 + 副文案，前 3 个放大 | 总览、团队页 |
| 卡片 | 白底圆角容器，标题 + 右上 hint | 全站 |
| 进度条 | 百分比条，可带文字 | 目标、佣金、覆盖率 |
| 环形 | 目标完成度 | 团队页、抽屉 |
| 柱状图 | 逐日战绩，带均值线与目标线 | 团队页 |
| 排名条 | 横向流水排名 | 总览 |
| 徽章 | 状态/达标/警示，5 色 | 全站 |
| 抽屉 | 成员详情 | 全站 |
| 骨架屏 | 加载态 | 首屏 |
